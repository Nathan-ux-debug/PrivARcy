Android setup steps
  1. Download the certificate, then open Android Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Menu names vary by phone; Android may require a screen lock.
  2. Verify the fingerprint above against PrivARcy before trusting the certificate.
  3. Return to this page and tap Continue securely.
iPhone or iPad setup steps
  1. Download the configuration profile. In Settings, tap Profile Downloaded, then install the PrivARcy profile.
  2. Open Settings → General → About → Certificate Trust Settings and enable full trust for the PrivARcy root certificate.
  3. Verify the fingerprint above against PrivARcy before enabling trust, then return here.
