Android setup steps
  1. Download the certificate, then inspect its SHA-256 fingerprint on your phone before installing it as a CA. It must match the fingerprint shown in PrivARcy; do not trust it if you cannot verify the match.
  2. Open Android Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Menu names vary by phone; Android may require a screen lock.
  3. Return to this page and tap Continue securely.
iPhone or iPad setup steps
  1. Download the configuration profile. Before enabling trust, inspect the certificate's SHA-256 fingerprint in the profile details; it must match the fingerprint shown in PrivARcy. Do not trust it if you cannot verify the match.
  2. In Settings, tap Profile Downloaded, then install the PrivARcy profile.
  3. Open Settings → General → About → Certificate Trust Settings and enable full trust for the PrivARcy root certificate.
  4. Return here only after verifying the installed certificate fingerprint against PrivARcy.
